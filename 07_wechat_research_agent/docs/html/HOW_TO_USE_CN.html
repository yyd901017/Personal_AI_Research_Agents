Personal AI Research Agents 微信公众号科研线索 Agent 使用说明

作者：Steven Yuandong Yue
Title：AI Research Tool Builder

这个 Agent 独立于 06_web_literature_agent，专门从微信公众号文章中发现科研论文线索。

1. 这个 Agent 是什么

它不是正式论文数据库搜索工具，而是帮助你从公众号文章里提取 DOI、论文标题、期刊等线索，再用 Crossref 验证正式论文。

公众号文章搜索入口
        ↓
找到公众号文章
        ↓
粘贴文章链接或正文
        ↓
提取 DOI / 论文标题线索
        ↓
用 Crossref 验证正式论文
        ↓
导出 Excel

2. 如何启动

D:\Projects_New Energy\Personal_AI_Research_Agents\07_wechat_research_agent\start_wechat_research_agent.bat

然后打开：

http://localhost:8502

3. 怎么用

  1. 输入搜索关键词，例如 PEM catalyst HEO、高熵氧化物 催化剂。
  2. 点击生成的 Open Search 外部搜索入口。
  3. 找到公众号文章后复制链接。
  4. 把链接粘贴到 公众号文章链接。
  5. 如果链接读取失败，把正文粘贴到 公众号文章正文。
  6. 点击 提取论文线索。
  7. 查看 DOI candidate、Title candidate、Crossref verified paper。
  8. 下载 Excel。

4. 当前限制

  • 不直接批量爬微信公众号。
  • 不读取个人微信聊天记录。
  • 不破解微信本地数据库。
  • 微信链接可能无法自动读取，正文粘贴更稳定。
  • 公众号文章只是科研线索来源，不是正式论文数据库。
  • Crossref 验证结果需要人工复核。
  • 还没有和 06_web_literature_agent 自动合并。

5. 和 ChatGPT-on-WeChat 的关系

你提供的文章讲的是公众号后台接入 AI bot，这需要公众号管理员权限、AppID、AppSecret、Token、EncodingAESKey、服务器、域名和 HTTPS。当前第一版先做更轻量安全的公众号搜索入口和论文线索提取。

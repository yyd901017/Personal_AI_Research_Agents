# Personal AI Research Agents

A personal toolkit for literature discovery and research-lead extraction.

This repository is a cleaned personal version. It does not include company materials, private project planning files, confidential legal files, API keys, local databases, virtual environments, or organization-specific branding.

## Included Tools

- `06_web_literature_agent`: Streamlit literature search agent for scholarly metadata sources such as Crossref, arXiv, OpenAlex, Semantic Scholar, and optional SerpAPI-based Google Scholar search.
- `07_wechat_research_agent`: Streamlit research-lead agent for finding public WeChat article leads, extracting DOI/title clues, and verifying candidates through Crossref.

## Quick Start

Run the literature agent:

```powershell
D:\Projects_New Energy\Personal_AI_Research_Agents\06_web_literature_agent\start_literature_agent.bat
```

Open:

```text
http://localhost:8501
```

Run the WeChat research agent:

```powershell
D:\Projects_New Energy\Personal_AI_Research_Agents\07_wechat_research_agent\start_wechat_research_agent.bat
```

Open:

```text
http://localhost:8502
```
